# Képfeltöltés

Ide töltsd fel a weboldal fotóit (JPG, PNG, HEIC vagy WebP, bármilyen méretben).
A fájlnév mindegy. Ha tudod, írd bele, mi van a képen (pl. `alma.jpg`, `pult.jpg`).

Feltöltés után a képeket átméretezzük, optimalizáljuk, és a helyükre tesszük az oldalon.

Amire szükség van:
- 1 nyitókép: sok gyümölcs, lehetőleg a saját pultotok (álló kép a legjobb)
- 3 üzletfotó: bejárat vagy kirakat, a pult, a csapat
- termékfotók: gyümölcsönként egy kép, lehetőleg egységes sötét háttér előtt, oldalfénnyel
